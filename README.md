## ✨ About The Project

**Oru Tea Sapdalama?** is a visually-driven landing page created to introduce and showcase a Tamil literary work through an immersive digital experience.

The website combines editorial typography, cinematic visuals, scroll-based animations, interactive book pages, and responsive layouts to create a digital experience inspired by the feeling of exploring a physical book.

The project was designed around the idea of turning a traditional book introduction into a **visual storytelling experience**.

---

## 🎯 Project Goals

The main goals of this project were to:

- Create a premium digital presence for a Tamil literary work
- Present the book through visual storytelling
- Experiment with advanced scroll-based animations
- Create an interactive book-page gallery
- Introduce the author and the Ezhuthupizhai Universe
- Build a responsive experience for desktop and mobile
- Combine editorial design with modern frontend interactions

---

## 🚀 Features

### 📖 Cinematic Hero Section

The hero section introduces **Oru Tea Sapdalama?** with a large visual book composition.

The floating book transitions smoothly into the following section as the user scrolls.

---

### 🎬 GSAP Scroll Animations

The project uses **GSAP + ScrollTrigger** to create smooth scroll-driven interactions.

Animations include:

- Book movement
- Scaling
- Rotation
- Position transitions
- Scroll-scrubbed animations
- Pinned gallery sections
- Animated connector lines
- Progressive gallery reveals

---

### 🖼️ Interactive Book Gallery

A dedicated **Book Journey** section allows visitors to explore selected pages from the book.

Features include:

- Six featured book pages
- Animated page positioning
- Scroll-based page reveals
- Connecting SVG lines
- Interactive page previews
- Full-screen image popup
- Gallery progress indicators

---

### 📚 Ezhuthupizhai Series

The website introduces the wider **Ezhuthupizhai Series** and its collection of literary works.

The author section presents the books as a visual bookshelf experience.

---

### ✍️ Author Showcase

A dedicated author section introduces:

**Mano Bharathi**

The section includes:

- Author portrait
- Biography
- Writer & Storyteller profile
- Literary background
- Ezhuthupizhai series
- Social media links

---

### ⭐ Reader Reviews

The website includes a dedicated testimonial section to present reader responses and impressions of the book.

---

### 📍 Contact & Location

The footer includes:

- Social media links
- Contact information
- Location information
- Embedded Google Maps
- Ezhuthupizhai social channels

---

### 📱 Responsive Design

The website has dedicated responsive behavior for desktop and mobile layouts.

GSAP's `matchMedia()` functionality is used to adapt animation behavior based on viewport size.

## 🔤 Typography

The project uses two Google Fonts to create an editorial visual identity.

### Manrope

Used for:

- Navigation
- Body text
- Labels
- UI elements

### Newsreader

Used for:

- Main headings
- Book titles
- Editorial sections
- Literary content

The combination creates a balance between a **modern interface and traditional editorial typography**.

---

## 🎨 Design Direction

The visual design is inspired by:

- Editorial magazines
- Literary publications
- Physical book layouts
- Minimal interfaces
- Warm visual tones
- Cinematic storytelling
- Modern motion design

The design intentionally keeps the interface clean so the **book and its content remain the primary focus**.
